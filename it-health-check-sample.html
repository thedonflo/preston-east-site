Executive Summary

Tidewater Dental is running a 22-person, three-location practice on a mix of legacy Windows Server, ad-hoc cloud backups, and shared admin passwords. The infrastructure works day-to-day, but HIPAA exposure is high, recovery from a ransomware event would take 5+ days, and the practice has no formal offboarding for departing staff. The fixes are mostly off-the-shelf — about six weeks of focused work to move from at-risk to healthy.

Overall posture: At risk

Top Findings

01. No MFA on email or PMSCritical
A single phished credential currently grants attacker access to patient records and email. Highest-probability incident path and the cheapest to close.
02. Backups never test-restoredCritical
If a ransomware event happened tomorrow, the practice has no proof its backups would actually restore. A test restore is a one-day exercise.
03. Shared admin accounts across 3 sitesHigh
Auditability is zero — when something changes, there is no record of who did it. Also a HIPAA finding if audited.
04. EOL Windows Server hosting imaging shareHigh
No security patches since EOL date; one CVE away from forced downtime. Migration to Azure file shares is a two-week project.
05. SaaS sprawl — 9 of 14 tools unusedMedium
~$1,400/mo in waste; each unused tool is also a credential set someone needs to remember. Quick audit clears both problems.

Recommended Next 90 Days

This Week — Quick Wins

  • Turn on MFA across M365 and the practice management system
  • Rotate shared admin credentials and create named admin accounts

Next 30 Days

  • Run a backup test-restore and document the RTO
  • Build an offboarding checklist; remove ex-staff from all systems
  • Audit and cancel unused SaaS subscriptions

60–90 Days

  • Migrate imaging share off EOL Windows Server to Azure file shares
  • Document HIPAA technical controls (encryption, access logging, audit trail)
  • Stand up a help ticketing channel so response times are measurable
